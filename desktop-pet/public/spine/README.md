Place your Spine export files here:

- `pet.skel` or `pet.json`
- `pet.atlas`
- one or more atlas page images such as `pet.png`

This project defaults to `pet.skel`. If your export is JSON, update
`SPINE_SKELETON_PATH` in `src/lib/pet-stage.ts`.

Keep the Spine Editor `major.minor` version aligned with the runtime package
version declared in `package.json`.
